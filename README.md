# NodeHub - Образовательная платформа по изучению Node.js

Дипломный проект. Веб-приложение на Flask + PostgreSQL для изучения Node.js с теоретическими уроками и тестированием.

## Технологии
- Python 3.10+, Flask, Flask-Login, Flask-WTF
- PostgreSQL (драйвер psycopg2)
- Bootstrap 5, Prism.js
- bcrypt для паролей
- pytest для тестирования
